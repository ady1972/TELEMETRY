# GOATS Telemetry — Pacchetti USB

## RC3.1 — Ripartenza dopo il salvataggio
Build da [e9d5c97](https://github.com/ady1972/TELEMETRY/commit/e9d5c97) con ESPHome 2026.7.3.

- [GOATS RT Manager Windows V5.4.15.15 — accesso alla modalità BOOT via USB](GOATS-RT-Manager-Windows-V5.4.15.15.zip)
- [Guition 4.3 RC3.1](GOATS-GUITION_43-RC3.1.zip)
- [RLCD 4.2 monocromatico RC3.1](GOATS-RLCD_MONO_42-RC3.1.zip)

In **Firmware USB**, rilevare il laptimer in modalità BOOT e scegliere
**Scarica RC3.1 da GitHub**. Per l'installazione offline usare lo ZIP
del modello e tenere insieme il firmware BIN e il manifesto JSON.
Le prove di compilazione e di ripartenza sono registrate nella
[PR RC3.1](https://github.com/ady1972/TELEMETRY/pull/37).

## Prima pubblicazione RC3

Build da [6ba487f](https://github.com/ady1972/TELEMETRY/commit/6ba487f) con ESPHome 2026.7.3.

- [GOATS RT Manager Windows V5.4.15.12](GOATS-RT-Manager-Windows-V5.4.15.12.zip)
- [Guition 4.3](GOATS-GUITION_43-RC3.zip)
- [RLCD 4.2 monocromatico](GOATS-RLCD_MONO_42-RC3.zip)

Aprire **Firmware USB** nel Manager. Rilevare il modello in modalità BOOT e scaricare il firmware da GitHub, oppure estrarre lo ZIP del modello e selezionare il file locale. Conservare il file BIN e il manifesto JSON insieme. Procedura e collaudo nella [PR RC3](https://github.com/ady1972/TELEMETRY/pull/37).
