GOATS RT Manager V5.4.13.11 - CLOUD SYNC ANDROID / PC

Base: V5.4.13.10_SESSIONS_TRACKS_STORAGE_FOLDER.

Modifiche:
- mantiene la scelta indipendente della cartella archivio sessioni e circuiti;
- aggiunge Cloud Sync file-level nella pagina Importa Sessioni;
- cartella cloud selezionabile (Google Drive, OneDrive, Dropbox, Synology Drive, ecc.);
- sincronizzazione manuale o automatica ogni 15 secondi;
- importa nel Manager i file sessione aggiunti dall'app Android;
- copia nel cloud i file sorgente delle sessioni importate sul PC;
- evita la reimportazione dei file caricati dal Manager nella stessa esecuzione;
- controllo sessioni equivalenti per ridurre duplicati dopo il riavvio;
- il database SQLite resta separato dalla sincronizzazione file-level, a meno che l'utente scelga esplicitamente una cartella cloud anche come archivio sessioni nelle Impostazioni.

Per la condivisione Android/PC è consigliato usare Cloud Sync sui file sessione e lasciare il database locale al PC.
