GOATS RT Manager V5.4.10.4 - IMPORT CSV DIRETTO

Aggiunto supporto ai file Sxxxxxx.CSV copiati dalla microSD tramite MODALITA USB SD.

Uso:
1. Copia Sxxxxxx.CSV dalla microSD al PC.
2. Apri Manager -> Importa.
3. SCEGLI FILE e seleziona uno o più CSV.
4. Il Manager legge direttamente i punti GPS e inserisce la sessione nel database.
5. La sessione compare subito in Sessioni e Analisi.

Supportati nei CSV:
elapsed_ms, lap, latitude, longitude, speed_kmh, heading_deg,
hdop, satellites, fix, free_recording.
Sono accettati anche diversi alias comuni e delimitatori ',' o ';'.

La versione resta V5.4.10.4.
Restano presenti Qt Windows Fix e compatibilità GSDT_WAIT.
