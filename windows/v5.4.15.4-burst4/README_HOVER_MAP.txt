GOATS RT Manager V5.4.10.4 - GRAFICO -> MAPPA

Versione invariata V5.4.10.4.

Nuova funzione in Analisi:
- passando il mouse sopra la curva Velocità / tempo, il Manager usa il tempo
  del punto grafico per trovare il campione GPS corrispondente;
- sulla mappa appare un marker ben visibile nel punto esatto del tracciato;
- in alto a destra della mappa vengono mostrati tempo e velocità;
- serie A = marker verde;
- eventuale serie B = marker giallo;
- uscendo dalla curva il marker scompare.

La ricerca sulla traccia completa usa elapsed_ms e quindi resta sincronizzata
anche quando il grafico è visualmente downsampled.

Restano invariati Import CSV, USB SD dal Manager, Qt Windows Fix e Analisi CSV.
