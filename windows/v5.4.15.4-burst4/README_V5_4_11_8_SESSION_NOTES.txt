GOATS RT Manager V5.4.11.9 - SESSION NOTES

Novita:
- Campo Note persistente per ogni sessione nel database SQLite.
- Pulsante NOTE SESSIONE nella pagina Sessioni.
- Anteprima Note nella tabella Sessioni.
- Ricerca estesa anche al testo delle note.
- Pannello NOTE SESSIONE direttamente nella pagina Analisi con SALVA NOTE.
- Migrazione automatica dei database esistenti: nessuna sessione precedente viene persa.
- Le note sono incluse nell export JSON della sessione.

Esempi d uso: assetto, gomme/pressioni, meteo, pilota, benzina, anomalie, modifiche tecniche e osservazioni.
