# GOATS Mobile — versioni Android

Ogni versione è conservata in una cartella con il progetto completo.

| Versione | Progetto |
|---|---|
| V0.2.3 — sessioni e cancellazioni condivise | [v0.2.3](v0.2.3/README.md) |
| V0.2.2 — sessioni e circuiti con Windows | [v0.2.2](v0.2.2/README.md) |
| V0.2.1 — Track Editor, Wi-Fi, Cloud Sync | [v0.2.1](v0.2.1/README.md) |

Per Android Studio, build e verifica dei checksum aprire la cartella della
versione, attualmente `mobile/v0.2.3/`. Il modulo Gradle resta `:app` e i
sorgenti sono in `fullapp/` all'interno di quel progetto.

Conservare ogni nuova versione completa in una nuova sottocartella e mantenere
le precedenti. Le note storiche incluse nel pacchetto restano nella sua cartella.

Consultare il [rapporto di migrazione](../docs/MIGRATION_MOBILE_WINDOWS_REPORT.md)
per provenienza, funzionalità e verifiche.
